# Roadmap

The [complete roadmap](https://github.com/Just-Nova23/Xiaomi-Watch-S1-Active-Modding/blob/main/ROADMAP.md) is maintained at the repository root. Immediate priorities are:

1. complete the `TSCFrameImage` packet description with synthetic fixtures;
2. build a visual decoder before attempting an encoder;
3. expand the compatibility matrix with hashes and reproduced versions;
4. document boundaries among native services, RPK apps, and the companion app;
5. turn every experimental patch into a repeatable test.

A roadmap entry is not an available feature. Verified capabilities remain listed under [Research status](status.md).
