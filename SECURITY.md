# Security policy

## Reporting

Do not open a public issue for credentials, private device data, a remotely
exploitable flaw, or a firmware path that could unexpectedly damage devices.
Use GitHub's private vulnerability reporting feature when it is available on
this repository.

For ordinary reproducible crashes, parser errors, or documentation problems,
use a normal issue after removing personal information and proprietary files.

## Scope

The repository contains research tools, not an official updater or a guaranteed
recovery system. Never attach secrets, firmware, account exports, full Bluetooth
logs, or device identifiers to a report.
