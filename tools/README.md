# Tools

This directory contains original, non-destructive utilities for local files.

- `firmware_pkg.py`: complete-package inspection and extraction;
- `diff_pkg.py`: differential-package inspection;
- `build_partial_diff.py`: experimental rebuilding of selected components;
- `asset_catalog.py`: GUI record indexing;
- `gui_animation.py`: outer GUI container round trips;
- `bitmap_catalog.py`: bitmap structure cataloging;
- `thumb_xrefs.py`: ARM Thumb references with Capstone;
- `patch_native_assistant_text_capacity.py`: patch guarded for the documented build.

No script starts an update or communicates with a device. The complete guide, including prerequisites and examples, is in [`docs/tools-reference.md`](../docs/tools-reference.md).
